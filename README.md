Plot-twist. — one word that sums up an ex. A tiny Node program that writes exactly that word to /output/entry.txt, nothing else attached, for make.fun's "Describe Your Ex in One Word" bounty.

## Run it

```sh
node main.ts
```

This writes `Plot-twist.` (11 characters) to `/output/entry.txt`. `OUTPUT_DIR` overrides the output directory for local runs.
